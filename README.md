# TechBox — магазин техники на Bootstrap

## Контрольная работа №2

Дисциплина: «Фронтенд и бэкенд разработка».

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

TechBox — учебный интернет-магазин техники и гаджетов: смартфоны, ноутбуки, аудио, планшеты, носимая электроника и аксессуары. Это отдельная реализация предметной области КР №1, сделанная заново на Bootstrap: вёрстка построена на сетке и компонентах фреймворка, а собственный `custom.css` только настраивает фирменный стиль.

GitHub Pages: https://keepmeinyourmind.github.io/kr2-bootstrap-shop/

## Используемый фреймворк

Bootstrap 5.3.8 (CSS + JS Bundle).

## Подключение Bootstrap

Bootstrap подключён **локально, без CDN**. Файлы compiled-версии фреймворка размещены в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Порядок подключения на каждой странице:

```html
<head>
  <link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
  <link rel="stylesheet" href="css/custom.css">
</head>
<body>
  ...
  <script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
  <script src="js/main.js"></script>
</body>
```

`custom.css` подключается после Bootstrap, чтобы его правила переопределяли стили фреймворка. JS Bundle нужен для мобильного меню, выпадающего списка, модального окна, карусели, accordion, вкладок, offcanvas и toast.

## Bootstrap-сетка

- `container` — ограничивает ширину контента на всех страницах;
- `row` + `g-*` — ряды с отступами между колонками (`g-2`, `g-3`, `g-4`, `g-lg-5`);
- `col-12`, `col-sm-6`, `col-md-*`, `col-lg-*`, `col-xl-4` — адаптивные колонки.

Как перестраивается каталог: 1 карточка в ряд на телефоне (`col-12`) → 2 на планшете (`col-md-6`) → 3 на широком экране (`col-xl-4`). Фильтры на `lg` и шире — отдельная колонка `col-lg-3`, на узких экранах — выезжающая панель `offcanvas-lg` по кнопке «Фильтры».

## Реализованные Bootstrap-компоненты

Обязательные:

- `navbar` — на всех страницах, с бургер-меню (`navbar-toggler` + `collapse`) и активным пунктом;
- `card` — карточки товаров, преимуществ, категорий, форм;
- `btn` — `btn-primary`, `btn-outline-primary`, `btn-outline-secondary`, `btn-light`, `btn-outline-light`, `btn-link`, размеры `btn-lg`;
- `badge` — метки «Хит», «Новинка», «Скидка», категории, количество товаров, процент скидки;
- `alert` — промо-акция (закрываемая), подсказки в каталоге и форме, «В наличии», сообщение об успешной заявке;
- `modal` — «Быстрый заказ» на главной, в каталоге и на страницах товаров;
- `form-control`, `form-select`, `input-group`, `form-check` (чекбоксы, радиокнопки, `form-switch`).

Дополнительные:

- `carousel` — hero-блок на главной;
- `accordion` — частые вопросы и этапы заказа;
- `nav-tabs` — описание, характеристики, доставка и отзывы на странице товара;
- `dropdown` — меню «Категории» в навигации;
- `offcanvas` — фильтры каталога на мобильных;
- `toast` — уведомление после отправки форм;
- `breadcrumb`, `list-group`, `table`, `ratio` (карта).

## Форма заявки (`order.html`)

Поля: имя, e-mail (`input-group` с `@`), телефон (`input-group` с `+7`), товар (`form-select`), количество, способ получения (радиокнопки `form-check`), оплата (`form-select`), адрес, комментарий, согласие на обработку данных (`form-check`), подписка (`form-switch`), кнопки «Отправить» и «Очистить».

У всех полей есть `label` и `name`, обязательные поля помечены `required`. Подсказки об ошибках — стандартная валидация Bootstrap (`needs-validation`, `was-validated`, `invalid-feedback`).

## JavaScript

Своего JS минимум — файл `js/main.js`:

1. При открытии модального окна «Быстрый заказ» подставляет название товара из атрибута `data-product` кнопки.
2. Проверяет формы по образцу из документации Bootstrap: при ошибке добавляет класс `was-validated`, при успехе показывает `alert` / `toast`. Данные никуда не отправляются — это учебный проект.

Форма фильтров в каталоге — статичная разметка на компонентах Bootstrap, без логики фильтрации.

## Самостоятельные доработки

1. **Локальное подключение Bootstrap** из `vendor/bootstrap/` вместо CDN.
2. **Дополнительные страницы**: `contacts.html` (карточки контактов, карта в `ratio`, форма обратной связи, FAQ) и отдельная страница для каждого из 9 товаров.
3. **Структура каталога**: товары сгруппированы по категориям с якорями (`catalog.html#audio`), на них ведут меню «Категории» и плитки на главной; фильтры — в боковой колонке, на телефоне — в `offcanvas`.
4. **Дополнительные компоненты**: `carousel`, `accordion`, `nav-tabs`, `dropdown`, `offcanvas`, `toast`, `breadcrumb`, `list-group`, `table`.
5. **Несколько вариантов карточек**: с фотографией, со старой ценой и скидкой, карточка-заглушка с логотипом для аксессуаров без фото.
6. **Улучшенная заявка**: быстрый заказ в модальном окне с названием товара; на `order.html` — выбор доставки и оплаты, блок «Условия заказа», этапы заказа в accordion, сообщение об успехе.
7. **Фирменный стиль через `custom.css`**, построенный на «молнии» из логотипа:
   - палитра: кобальтовый синий `#1f3bff`, сигнальный жёлтый `#ffd23f`, тёмный `#16181d`, светло-серый фон-«витрина» `#eef0f3`;
   - шрифты Unbounded (заголовки и цены) и Onest (текст) подключены локально через `@font-face` из папки `fonts/`: по одному файлу на шрифт, в каждом все начертания от 400 до 700;
   - размеры заголовков заданы классами Bootstrap (`display-5`, `fs-1`, стандартные `h1`/`h2`), а `custom.css` меняет только шрифт и начертание;
   - цвета Bootstrap переопределены через CSS-переменные (`--bs-primary`, `--bs-warning`, `--bs-btn-*`, `--bs-body-font-family`), а не переписыванием компонентов;
   - hero — кобальтовая панель с каруселью, преимущества — полоса с разделителями, плитки категорий, плоские карточки товаров без теней;
   - тёмный подвал сделан встроенным механизмом Bootstrap `data-bs-theme="dark"`;
8. **Доступность**: ссылка «Перейти к содержимому», `aria-current` у активного пункта меню, `aria-label` у кнопок-иконок, подписи у всех полей.

## Как проверить проект

1. Открыть опубликованную версию или `index.html` в браузере.
2. Уменьшить окно до ширины телефона (DevTools → Device Toolbar): меню сворачивается в бургер, карточки встают в одну колонку, фильтры открываются кнопкой «Фильтры».
3. На главной: пролистать карусель, раскрыть вопросы в accordion, нажать «Заказать» у товара — откроется модальное окно с названием товара.
4. В навигации открыть «Категории» → «Аудио» — каталог откроется на разделе «Аудио».
5. На странице товара переключить вкладки «Описание», «Характеристики», «Доставка», «Отзывы».
6. На `order.html` отправить пустую форму (появятся подсказки), затем заполнить и отправить (появятся сообщение об успехе и toast).
