# TechBox — магазин техники на Bootstrap

## Контрольная работа №2

Дисциплина: «Фронтенд и бэкенд разработка».

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

TechBox — учебный интернет-магазин техники и гаджетов: смартфоны, ноутбуки, аудио, планшеты, носимая электроника и аксессуары. Это отдельная реализация предметной области КР №1, сделанная заново на Bootstrap: вёрстка построена на сетке и компонентах фреймворка, а собственный `custom.css` только настраивает фирменный стиль.

GitHub Pages: https://keepmeinyourmind.github.io/kr2-bootstrap-shop/

## Используемый фреймворк

Bootstrap 5.3.8 (CSS + JS Bundle).

## Подключение Bootstrap

Bootstrap подключён **локально, без CDN**. Файлы compiled-версии фреймворка размещены в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Порядок подключения на каждой странице:

```html
<head>
  <link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
  <link rel="stylesheet" href="css/custom.css">
</head>
<body>
  ...
  <script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
  <script src="js/main.js"></script>
</body>
```

`custom.css` подключается после Bootstrap, чтобы его правила переопределяли стили фреймворка. JS Bundle нужен для мобильного меню, выпадающего списка, модального окна, карусели, accordion, вкладок, offcanvas и toast.

## Bootstrap-сетка

- `container` — ограничивает ширину контента на всех страницах;
- `row` + `g-*` — ряды с отступами между колонками (`g-2`, `g-3`, `g-4`, `g-lg-5`);
- `col-6`, `col-12`, `col-sm-6`, `col-md-*`, `col-lg-*` — адаптивные колонки.

Примеры перестройки:

- популярные товары на главной: 2 в ряд на телефоне (`col-6`) → 3 на планшете (`col-md-4`) → 6 на широком экране (`col-lg-2`);
- раздел каталога: на телефоне название категории над товарами, от `lg` — слева (`col-lg-3`), товары справа (`col-lg-9`) по 2–3 в ряд;
- страница товара: фото и описание друг под другом, от `lg` — рядом (`col-lg-7` + `col-lg-5`);
- заявка: форма (`col-lg-8`) и блок «Условия заказа» (`col-lg-4`), поля формы по два в ряд от `md`.

## Реализованные Bootstrap-компоненты

Обязательные:

- `navbar` — на всех страницах, с бургер-меню (`navbar-toggler` + `collapse`), выпадающим меню «Каталог» и активным пунктом;
- `card` — карточки товаров;
- `btn` — `btn-dark` (главное действие), `btn-outline-dark` (второстепенное), размер `btn-sm`, скругление `rounded-pill`;
- `badge` — метки «Хит», «Новинка», «Скидка», промокод, «Бесплатно»;
- `alert` — промокод (закрываемый), подсказки в каталоге и форме, «В наличии», сообщение об успешной заявке;
- `modal` — «Быстрый заказ» на главной, в каталоге и на страницах товаров;
- `form-control`, `form-select`, `input-group`, `form-check` (чекбоксы, радиокнопки, `form-switch`).

Дополнительные:

- `carousel` — три слайда на главной (с точками-индикаторами);
- `accordion` (`accordion-flush`) — вопросы и ответы, этапы заказа;
- вкладки (`data-bs-toggle="tab"`, стиль `nav-underline`) — описание, характеристики и доставка на странице товара;
- `dropdown` — меню «Каталог» в навигации;
- `offcanvas` — панель фильтров в каталоге;
- `toast` — уведомление после отправки форм;
- `breadcrumb`, `list-group`, `table`, `ratio` (карта).

## Форма заявки (`order.html`)

Поля: имя, e-mail (`input-group` с `@`), телефон (`input-group` с `+7`), товар (`form-select`), количество, способ получения (радиокнопки `form-check`), оплата (`form-select`), адрес, комментарий, согласие на обработку данных (`form-check`), подписка (`form-switch`), кнопки «Отправить» и «Очистить».

У всех полей есть `label` и `name`, обязательные поля помечены `required`. Подсказки об ошибках — стандартная валидация Bootstrap (`needs-validation`, `was-validated`, `invalid-feedback`).

## JavaScript

Своего JS минимум — файл `js/main.js`:

1. При открытии модального окна «Быстрый заказ» подставляет название товара из атрибута `data-product` кнопки.
2. Проверяет формы по образцу из документации Bootstrap: при ошибке добавляет класс `was-validated`, при успехе показывает `alert` / `toast`. Данные никуда не отправляются — это учебный проект.

Остальной интерактив (меню, модальное окно, карусель, accordion, вкладки, offcanvas) работает через Bootstrap JS Bundle и атрибуты `data-bs-*`. Форма фильтров в каталоге — статичная разметка, без логики фильтрации.

## Самостоятельные доработки

1. **Локальное подключение Bootstrap** из `vendor/bootstrap/` вместо CDN.
2. **Дополнительные страницы**: `contacts.html` (контакты, карта в `ratio`, форма обратной связи, вопросы) и отдельная страница для каждого из 9 товаров.
3. **Структура каталога**: товары сгруппированы по категориям с якорями (`catalog.html#audio`), на них ведут меню «Каталог», вкладки разделов и подвал; поиск, сортировка и фильтры в выезжающей панели.
4. **Дополнительные компоненты**: `carousel`, `accordion`, вкладки, `dropdown`, `offcanvas`, `toast`, `breadcrumb`, `list-group`, `table`.
5. **Несколько вариантов карточек**: обычная, со значком «Хит» / «Новинка», со скидкой (тёмный значок и зачёркнутая старая цена).
6. **Улучшенная заявка**: быстрый заказ в модальном окне с названием товара; на `order.html` — выбор доставки и оплаты, блок «Условия заказа», этапы заказа в accordion, сообщение об успехе.
7. **Строгий минималистичный стиль через `custom.css`**:
   - палитра без ярких цветов: графитовый `#1d1d1f`, серый `#6e6e73`, линии `#e3e3e6`, светло-серый `#f5f5f7`, белый фон;
   - шрифт Onest подключён локально через `@font-face` из папки `fonts/`;
   - цвета Bootstrap переопределены через CSS-переменные (`--bs-body-color`, `--bs-primary`, `--bs-btn-*`, `--bs-accordion-*`), а не переписыванием компонентов;
   - центрированные слайды и заголовки, фото товаров в тонкой рамке, кнопки-«таблетки», ссылки-действия с подчёркиванием.
8. **Доступность**: `aria-current` у активного пункта меню, `aria-label` у кнопок без текста, подписи у всех полей, `alt` у фотографий.

## Как проверить проект

1. Открыть опубликованную версию или `index.html` в браузере.
2. Уменьшить окно до ширины телефона (DevTools → Device Toolbar): меню сворачивается в бургер, товары встают по 2 в ряд, разделы каталога — в одну колонку.
3. На главной: пролистать карусель, раскрыть вопросы в accordion, нажать «Заказать» у товара — откроется модальное окно с названием товара.
4. В навигации открыть «Каталог» → «Аудио» — каталог откроется на разделе «Аудио». В каталоге нажать «Фильтры» — выедет панель.
5. На странице товара переключить вкладки «Описание», «Характеристики», «Доставка».
6. На `order.html` отправить пустую форму (появятся подсказки), затем заполнить и отправить (появятся сообщение об успехе и toast).
